# 🛡️ 시스템 무결성 검증 및 테스트 실행 정책

## 1. 상시 전수 검사 금지 원칙
- 매 턴마다, 또는 사소한 코드/문서 편집 시마다 `verify_total_integrity.py` 등의 전체 검사 스크립트를 습관적으로 자동 실행하지 않는다.
- 불필요한 반복 검사로 인한 토큰 낭비, 응답 지연 및 작업 흐름 중단을 원천 방지한다.

## 2. 검사 실행 허용 조건 (오직 다음 경우에만 실행)
1. **대규모 업데이트 완료 시**: 핵심 시스템 코어, 런타임, DB 아키텍처 등 광범위한 변경이 일단락되었을 때.
2. **주기적 마일스톤 점검 시**: 특정 Phase나 Milestone 전체가 완결되는 시점.
3. **사용자의 명시적 요청 시**: 사용자가 "검사해줘", "테스트 돌려봐", "무결성 확인해줘"라고 직접 지시했을 때.
4. **에이전트의 필수 판단 시**: 코드 변경으로 인해 다른 모듈과의 결합이 깨질 위험이 높아 반드시 확인이 필요하다고 판단될 때.

## 3. 일반 작업 시의 행동 지침
- 단순 문서 정리(`구현.md` 등), 단일 함수 수정, 질의응답, 리팩토링 중에는 검사를 생략하고 신속하고 정확하게 작업을 완수한다.
