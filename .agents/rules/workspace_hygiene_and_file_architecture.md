# 📁 효율적인 파일 구조 및 저장소 위생(Workspace Hygiene) 표준 규칙

본 규칙은 Yggdrasil 프로젝트 내 파일 난개발, 데드코드 방치, 아키텍처 규격 위반을 원천 차단하고 최고 수준의 저장소 위생을 유지하기 위한 필수 엔지니어링 표준입니다.

---

## 1. 루트 청결 원칙 (Zero-Root Pollution)
- **루트 임시 파일 생성 절대 금지**: 프로젝트 최상위 루트에 일회성 테스트 스크립트(`test_*.py`), 마이그레이션 도구, 임시 JSON 덤프, 스크래치 파일을 직접 생성하는 것을 전면 금지한다.
- **테스트 디렉터리 엄격 격리**: 모든 검증, 단위 테스트, 무결성 검사 스크립트는 반드시 `tests/` 디렉터리 내에만 위치시키고 체계적으로 관리한다.
- **빈 디렉터리 방치 금지**: 작업 도중 발생한 빈 껍데기 폴더(0바이트 디렉터리)는 발견 즉시 영구 삭제한다.

---

## 2. 빅스비 캡슐 공식 아키텍처 준수 (Bixby Structure Separation)
- **Concepts 폴더 2대 분류 강제**: `models/concepts/` 바로 아래에 파일을 평면(Flat) 배치하지 않고, 반드시 규격화된 하위 폴더에 배치한다:
  - `models/concepts/primitive/`: `text`, `integer`, `boolean`, `decimal`, `enum` 등 단일 속성 모델 전용
  - `models/concepts/structures/`: 복합 다중 프로퍼티를 갖는 `structure` 모델 전용
- **캡슐 내 유령/중복 폴더 금지**: 캡슐 내부에 캡슐명과 동일한 중첩 폴더를 생성하거나 방치하지 않는다.
- **코드 디렉터리 경량화**: `code/` 내부에 호출처가 없는 데드코드나 미사용 라이브러리를 남겨두지 않는다.

---

## 3. 안드로이드 리소스 및 에셋 정상 위치 단일화 (Asset Placement)
- **표류 파일 금지**: C++이나 Android 앱에서 읽어야 하는 설정 파일, 도구 스키마(`*.json`), 프롬프트 템플릿 등은 상위 디렉터리에 분산시키지 않는다.
- **Android Assets 단일화**: 앱 런타임 리소스는 반드시 `core/android/app/src/main/assets/` 내에만 위치시켜 APK 패키징 누락을 원천 방지한다.

---

## 4. 대용량 AI 바이너리 Git 추적 원천 차단 (Sub-Gigabyte Safety)
- **500MB+ 바이너리 Git 커밋 금지**: 1.5GB GGUF 모델 가중치 파일 등 대용량 바이너리는 절대 Git 트래킹 대상에 포함하지 않으며, 항상 `.gitignore`에 등록하여 격리한다.
- **단말 주입 파이프라인 전용화**: 대용량 모델 배포는 `build_and_deploy.py` (adb push) 전용 도구를 통해서만 수행한다.

---

## 5. 죽은 코드 즉시 제거 원칙 (Zero-Zombie Policy)
- **호출처 0건 파일 즉각 폐기**: 아키텍처 전환이나 리팩토링으로 인해 더 이상 사용되지 않는 모듈(예: 구 로컬 HTTP 소켓 통신 파일)은 주석 처리나 보류 없이 발견 즉시 영구 삭제한다.
- **주석 처리된 대량 코드 방치 금지**: Git 히스토리가 보존되므로 파일 내부에 수십 줄 이상의 주석 처리된 구버전 코드를 남기지 않는다.
