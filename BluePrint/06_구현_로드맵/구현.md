## ⚔️ 3. 직설적이고 냉혹한(Roasted) 엔지니어링 코드 검토 & 필수 추가 개선점

```text
┌────────────────────────────────────────────────────────────────────────┐
│               ROASTED CODE REVIEW: 안이함을 도려내는 현실 진단            │
├────────────────────────────────────────────────────────────────────────┤
│ "기능이 돌아간다고 끝난 게 아니다. 실사용 단말기 24시간 필드에서 터질    │
│  잠재적 지뢰와 물리 법칙(배터리, 메모리, 타이밍)을 직시해야 한다."     │
└────────────────────────────────────────────────────────────────────────┘
```

### 1. [과제 1 - Stop Token] 겉보기엔 완벽하지만 터질 수 있는 엣지 케이스

- **지적 (Roasted)**:
  - 문자열 기반 슬라이딩 버퍼는 UTF-8 멀티바이트 문자가 토큰 경계에서 잘릴 때(예: 한글 3바이트 중 1바이트만 먼저 들어옴) 문자열 인덱싱 에러나 깨진 바이트가 임시 방출될 위험이 있다.
- **실전 개선 조치**:
  - `piece`가 완전한 UTF-8 시퀀스인지 검증하는 유효성 검사 또는 버퍼 플러시 시 불완전한 UTF-8 트레일링 바이트를 다음 루프로 홀드하는 방어 로직을 보강해야 한다.

### 2. [과제 2 - 화면 제어 & FLAG_SECURE] 슬립(Sleep)과 레이아웃 지연의 덫

- **지적 (Roasted)**:
  - `Thread.sleep(400)`은 전형적인 블로킹 휴리스틱이다. 안드로이드 저가형 기기나 고부하 상황에서는 400ms 내에 스크롤 렌더링이 완료되지 않아 OCR이 이전 화면 잔상을 읽을 수 있고, 반대로 S26 Ultra 120Hz 화면에서는 100ms면 충분한데 쓸데없이 400ms를 낭비한다.
- **실전 개선 조치**:
  - `AccessibilityEvent.TYPE_VIEW_SCROLLED` 이벤트를 수신하여 스크롤 완료를 이벤트 드리븐(Event-driven)으로 감지하고 즉시 다음 단계로 넘어가야 최저 지연시간(SLA)을 달성할 수 있다.
  - `FLAG_SECURE` 블랙아웃 감지 시, 사용자가 직접 화면을 터치할 때까지 대기하는 타임아웃(15초) 가드레일을 연결해야 루프가 영구 고착되지 않는다.

### 3. [과제 3 - 4096-ctx & 페르소나 Pinning] 단순 절단 요약의 한계

- **지적 (Roasted)**:
  - 현재 1줄 요약은 앞 40자만 자르는 단순 문자열 절단(`substr`)이다. 사용자가 장문의 복잡한 업무 지시나 중요한 보안 키를 대화 중에 넘겼다면, 40자 밖으로 밀려나 잘려버리는 정보 유실(Information Loss)이 발생한다.
- **실전 개선 조치**:
  - 백그라운드 유휴 시간(Idle time)에 온디바이스 NPU를 이용해 탈락하는 턴을 실제 1줄 요약 프롬프트(`"핵심만 1줄로 요약해줘"`)로 압축하는 `On-device Asynchronous Micro-Summarizer`로 진화시켜야 한다.

### 4. [과제 4 - NPU / GPU 가속] NDK 런타임 공유 라이브러리 누락 위험

- **지적 (Roasted)**:
  - CMake 플래그(`GGML_HEXAGON=ON`)만 켠다고 끝이 아니다. 실제 단말기에 Qualcomm Hexagon SDK 런타임 공유 라이브러리(`libhexagon_controller.so`, `libggml-htp-v75.so` 등)가 APK의 `jniLibs/arm64-v8a`에 실제로 패키징되어 있지 않으면 런타임에 `dlopen` 실패로 조용히 CPU 폴백이 일어난다.
- **실전 개선 조치**:
  - Gradle `sourceSets.main.jniLibs`에 Hexagon NPU 및 Vulkan 프리빌트 컴파일러 산출물 폴더 경로를 명시적으로 매핑하고, 앱 부팅 시 `LocalLlmService`에서 `getActiveBackendName()`을 검사하여 CPU 폴백 발생 시 즉시 개발자 로그 및 대시보드에 경고를 표기해야 한다.

## 🎙️ 자체 음성 핸즈프리 아키텍처 (On-Device Hotword Wake-up)

### 1. 기술적 목표

빅스비 캡슐의 `"이그드라실에서 ~"`라는 거추장스러운 접두어를 영구 폐기하고, 공중에 대고 **"이그드라실"**이라는 커스텀 호출어 한마디로 0.1초 만에 스마트폰을 깨워 즉각 작업을 지시하는 100% 독립형 핸즈프리 체계 구축.

### 2. 3단계 초저전력 파이프라인

1. **초저전력 음성 활동 감지 (VAD - Voice Activity Detection)**:
   - 마이크 입력 중 배경 소음과 사람 목소리를 구분하여, 사람이 말할 때만 연산 파이프라인 활성화 (배터리 방전 원천 차단).
2. **온디바이스 핫워드 감지 (Picovoice Porcupine / OpenWakeWord)**:
   - 400KB 미만의 초경량 신경망 모델이 단말기 백그라운드에서 상시 대기.
   - `"이그드라실"` 웨이크워드 감지 시 즉시 0.05초 만에 `WakeLock` 획득 및 음성 캡처 스트림 오픈.
3. **온디바이스 고속 STT & ReAct 자율 액션 루프 구동**:
   - 이어지는 사용자 발화를 Whisper.tflite 또는 Android On-Device SpeechRecognizer로 실시간 텍스트화.
   - `VoiceInteractionService` 오버레이를 통해 화면 인식(Vision) 및 접근성 자율 조작(Action) 즉각 개시.

### 3. 24시간 배터리 방어 원칙 (Sub-Watt Rule)
- **대기 상태**: 0.05W 미만 마이크 저전력 버퍼링 유지
- **호출 순간**: NPU 연산으로 초고속 추론 완료 후 즉각 Doze 모드로 복귀 (Race-to-Sleep)

  - 온디바이스 `SharedPreferences` 금고에 사용자 고유 보이스 프로필로 암호화 영구 보관.
- **적응형 정밀 판별 가드레일**:
  - $F_0 \in [F_0\text{ mean} \pm 2.5\sigma]$ 대역(30~55Hz 적응형 톨러런스) 검증으로 감기나 피로로 인한 본인 기각률(FRR) 방어.

## 👤 능동적 음역대 온라인 적응 학습 (Adaptive Online Dataset Expansion)

### 1. 깐깐한 고정 음역대 폐기 및 능동적 데이터셋 확장 (`YggdrasilVoiceprintVerifier.kt`)
- **광대역 동적 가우시안 톨러런스 ($\pm 55\text{Hz} \sim 95\text{Hz}$)**:
  - 기존의 좁은 고정 대역(30~55Hz)을 폐기하여 일상 대화의 억양 굴곡, 빠른 발화, 감정 기복으로 인한 본인 기각을 원천 방지.
  - 코사인 유사도 기준을 `0.62f`로 유연화하여 자연스러운 발화 수용.
- **실시간 점진 프로필 갱신 (Online Incremental Learning)**:
  - 어시스턴트 호출이 성공할 때마다 해당 발화의 유효 $F_0$와 13차원 MFCC 특징을 최근 데이터셋에 누적.
  - 가중 이동 평균(Moving Average, $\alpha = 0.08$)으로 사용자의 실제 목소리 변화(아침/저녁, 피로도, 목소리 톤)에 맞춰 보이스 프로필이 스스로 진화하도록 구현.

  - **단일 프레임 데시메이션(Aliasing) 왜곡 완전 폐기**: 전체 버퍼를 512샘플로 건너뛰기 다운샘플링하여 주파수를 250Hz로 파괴하던 결함을 제거하고, 25ms 윈도우(400샘플) / 10ms 홉(160샘플) **STFT(Short-Time Fourier Transform) 다중 프레임 시계열 분석** 파이프라인으로 전면 개편.
  - **20채널 삼각 멜 필터뱅크(Triangular Mel Filterbank) 행렬화**: 100Hz ~ 7500Hz 인간 가청 성도 대역을 정밀 커버하는 멜 스케일 삼각 가중치 행렬을 사전 계산(Precomputed)하여 실시간 고속 연산 및 Zero-Allocation 달성.
  - **24차원 성도 동특성(Acoustic Vocal Tract) 임베딩**:
    - 12차원 Temporal Mean: 발화 전반에 걸친 구강 및 인두 강 고유 공명 주파수(성도 형태)
    - 12차원 Temporal Standard Deviation: 발화 중 음소 간 조음 속도 및 음색 변화율(조음 동특성)
    - 음량 크기에 따라 요동치는 $c_0$ 에너지는 원천 배제하여 마이크 거리/볼륨 불변성 확보.
  - **멀티프레임 중앙값(Median) F0 피치 추적기**: 순간 노이즈나 일시적 음성 갈라짐에 취약한 단일 프레임 피치 추정을 폐기하고, 활성 음성 프레임들의 주기성(Harmonic Strength $\ge 0.38$) 후보군 중 중앙값을 채택하여 옥타브 도약 완벽 차단.
