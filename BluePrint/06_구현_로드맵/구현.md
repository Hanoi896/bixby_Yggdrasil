### 과제 1. LG EXAONE 턴 종료 멈춤 토큰(`[|endofturn|]`) 감지 및 자문자답 환각 차단 (P0 - 치명적)

- **현실 결함 분석**:
  - [ExaoneRuntime.cpp](file:///c:/Users/nhj23/bixby-workspace/bixby_Yggdrasil/core/android/app/src/main/cpp/ExaoneRuntime.cpp)의 토큰 생성 루프가 표준 EOG/EOS 토큰 ID만 체크하고 있음.
  - LG EXAONE 3.0 모델은 공식 턴 종료 시 `[|endofturn|]` 문자열을 생성함. 이를 감지하지 못하면 혼자서 `[|user|] 또 다른 질문 있어? [|assistant|] 네...`라며 1024 토큰 끝까지 자문자답 헛소리를 쏟아내는 환각 루프 발생.
- **필수 구현 명세**:
  - [ ] **Stop Sequence 인터셉터 실장**: 실시간 생성 텍스트 버퍼에서 `[|endofturn|]` 또는 `[|user|]` 감지 즉시 토큰 생성 루프 탈출(`break`).
  - [ ] **특수 토큰 클렌징**: UI에 노출되는 스트리밍 텍스트에서 특수 제어 토큰 마크업 필터링.

### 과제 2. 화면 제어 스크롤 탐색(Scroll-and-Retry) 및 금융앱 블랙아웃(`FLAG_SECURE`) 감지 (P0 - 치명적)

- **현실 결함 분석**:
  - [ScreenCaptureManager.kt](file:///c:/Users/nhj23/bixby-workspace/bixby_Yggdrasil/core/android/app/src/main/java/com/yggdrasil/assistant/operator/ScreenCaptureManager.kt)가 현재 단일 뷰포트만 분석하여, 버튼이 화면 아래에 숨겨져 있으면 즉시 실패함.
  - 금융앱 및 보안 화면(`FLAG_SECURE`) 캡처 시 100% 새까만 화면(Black Screen)만 전달되어 AI가 먹통이 됨.
- **필수 구현 명세**:
  - [ ] **에이전트 스크롤 탐색 루프 (Scroll-and-Retry)**: 타깃 미발견 시 `dispatchGesture`로 화면을 아래로 스와이프(1~2회) 후 비트맵 OCR 재시도.
  - [ ] **FLAG_SECURE 감지 및 음성 핸드오프**: 캡처 비트맵이 순수 검은색(`0xFF000000`)일 때 보안 화면으로 판정하고, 음성 TTS로 *"보안 화면이 감지되었습니다. 직접 입력해주세요"* 안내.

### 과제 3. 장기 대화 4096-ctx 초과 방지 시스템 프롬프트(페르소나) 영구 고정(Pinning) (P1 - 중요)

- **현실 결함 분석**:
  - 4096 컨텍스트 한계 도달 시 앞부분 토큰을 무식하게 잘라내어, 대화가 20턴 이상 지속되면 프롬프트 맨 앞의 `[|system|]` 페르소나(사용자 호칭, 어투)가 지워져 정체성을 상실함.
- **필수 구현 명세**:
  - [ ] **시스템 프롬프트 영구 고정 (Pinning)**: 슬라이딩 윈도우 동작 시 시스템 프롬프트는 영구 보존하고, 오래된 대화 턴만 우선 팝(Pop).
  - [ ] **중간 대화 자동 요약 (Auto-Summarizer)**: 탈락하는 오래된 대화 쌍의 핵심 맥락을 1줄로 압축하여 시스템 프롬프트 직후에 주입.

### 과제 4. Snapdragon 8 Elite QNN NPU / Vulkan GPU 하드웨어 가속 라이브러리 연동 (P1 - 중요)

- **현실 결함 분석**:
  - [CMakeLists.txt](file:///c:/Users/nhj23/bixby-workspace/bixby_Yggdrasil/core/android/app/src/main/cpp/CMakeLists.txt)에 ARM NEON CPU 백엔드만 기본 탑재되어, NPU 가속 없이 CPU 6코어가 풀로드(Full-Load)로 돌아 단말기 발열과 스로틀링 발생.
- **필수 구현 명세**:
  - [ ] **Vulkan GPU 백엔드 빌드 플래그 활성화 (`GGML_VULKAN=ON`)**: Adreno 830 GPU로 Attention/FFN 레이어 오프로딩.
  - [ ] **Qualcomm QNN Hexagon HTP 드라이버 연동**: NPU 전용 추론 인터페이스 연결을 통해 전력 소모 1.2W 미만 유지.
