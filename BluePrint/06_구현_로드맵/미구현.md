### 1.2 Android 15 및 S26 Ultra 16KB Page Size 호환성 크래시 방어

- **미구현 잔여 작업**:
  - [x] CMake 및 NDK 컴파일러 링커 플래그에 `-Wl,-z,max-page-size=16384` 적용
  - [ ] 16KB 페이지 지원 안드로이드 15 에뮬레이터 및 실기기에서 JNI `.so` 로딩 무결성 검증

### 1.3 모바일 MCP 연동 시 4096 컨텍스트 윈도우 폭탄 방어 (Dynamic Pruning)

- **현실 지뢰 (Roasted)**:
  - 데스크톱 MCP 서버 3~4개의 JSON Schema 명세만으로 **2,500토큰**을 소모함.
  - 컨텍스트 한계가 4096토큰인 EXAONE 2.4B에 이를 날것으로 주입하면, 질문 두 문장 만에 토큰 한도를 넘어 OOM 크래시가 나거나 페르소나와 이전 대화가 통째로 증발함.
- **미구현 잔여 작업**:
  - [x] 전체 도구를 주입하지 않고, 사용자 발화 임베딩(BM25 + 코사인)과 연관도 높은 상위 3개 도구만 선별 주입(800토큰 이내)하는 `DynamicToolPruningFilter` 실장
  - [x] 모바일 OS 제약에 맞춰 `stdio` 의존성을 배제하고 로컬 IPC 및 인메모리 호출을 지원하는 순수 Kotlin `LocalMcpRegistry` 코어 구축

### 1.4 보안 앱(`FLAG_SECURE`) 및 생체 인증 자율 조작 불가능성 (핸드오프 가드레일)

- **현실 지뢰 (Roasted)**:

  - 지문 데이터는 하드웨어 보안 칩(Knox/TEE)에 갇혀 있어 앱이 읽거나 꺼낼 수 없음. AI가 로그인이나 송금을 대신 해준다는 것은 안드로이드 보안 아키텍처상 100% 불가능한 환상임.
- **미구현 잔여 작업**:
  - [ ] 보안 화면/키패드 진입 감지 즉시 조작을 중단하고 0ms에 사용자에게 지문 직접 입력을 유도하는 음성 핸드오프(Voice Handoff) 강제 실장
  - [x] StrongBox/TEE 하드웨어 키스토어 기반 자격증명 볼트(`BiometricCredentialVault`) 및 OAuth 2.0 PKCE 표준 소셜 로그인 엔진(`OAuth2PkceFlowManager`) 구축
  - [x] 2FA SMS 인증번호 자동 스니핑 & 주입(`OtpSmsAutoSniffer`) 실장

### 1.5 화면 꺼짐(Screen-off) 상태 OS 백그라운드 캡처 차단 대응 (Secure Wake-up)

- **현실 지뢰 (Roasted)**:

- **미구현 잔여 작업**:
  - [ ] 화면 인식이 필요한 명령 수신 시, `KeyguardManager` 및 `PowerManager.ACQUIRE_CAUSES_WAKEUP`으로 화면을 먼저 켠 뒤 락스크린 상단에 세션을 띄우는(`setShowWhenLocked(true)`) 절차 선행 파이프라인 실장

### 2.2 비전 OCR(ML Kit) 1-Shot 탭의 지연시간 단축 (Template Coordinate Cache)

- **미구현 잔여 작업**:

### 2.3 2.4B 소형 모델의 JSON 도구 파라미터 문법 파손 자동 교정 (JsonSanitizer)

- **현실 지뢰 (Roasted)**:

- **미구현 잔여 작업**:
  - [x] NPU 출력 텍스트 수신 즉시 불완전한 JSON을 0ms에 교정하는 `Robust JsonSanitizer` 및 정규식 기반 인자 복원 가드레일 실장

### 2.4 연속 대화 시 주제 급변에 따른 KV 캐시 슬롯 오염 (Selective KV Pruning)

- **현실 지뢰 (Roasted)**:

- **미구현 잔여 작업**:

### 2.5 무닌 SQLCipher 대용량 누적 시 O(N) 풀스캔 병목 (FTS5 인덱스)
