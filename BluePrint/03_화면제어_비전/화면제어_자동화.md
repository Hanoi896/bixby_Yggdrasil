# 📱 모바일 화면 제어 및 UI 자동화 설계 청사진 (`화면제어_자동화.md`)

> **핵심 과제**: 안드로이드 OS 접근성 서비스(`AccessibilityService`)와 온디바이스 Vision ML Kit OCR을 결합하여, 사용자가 보는 스마트폰 화면을 직접 보고 터치/입력하는 자율 디바이스 오퍼레이터(Operator) 구현.

---

## 📑 핵심 아키텍처

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   Hugin / Gungnir 자율 오퍼레이터                     │
│  - ScreenOperatorController.kt: 복합 UI 제어 시나리오 플래너           │
└──────────────────┬─────────────────────────────────┬───────────────────┘
                   │                                 │
┌──────────────────▼────────────────┐┌───────────────▼───────────────────┐
│     화면 인지 (Vision & OCR)       ││      화면 조작 (Accessibility)    │
│  - MediaProjection 1-shot 캡처    ││  - YggdrasilAccessibilityService  │
│  - Google ML Kit 한국어 온디바이스││  - dispatchGesture 정밀 탭/스와이프│
│  - 바운딩 박스 & 버튼 판정 휴리스틱││  - Text Injection 키보드 자동 입력 │
└───────────────────────────────────┘└───────────────────────────────────┘
                   │                                 │
                   └────────────────┬────────────────┘
                                    │ (Fail-Safe)
┌───────────────────────────────────▼────────────────────────────────────┐
│                       안전 가드레일 (Safety Guardrail)                 │
│  - 사용자 화면 직접 터치 시 AI 제어 즉시 강제 중단 (Fail-Safe 인터럽트) │
│  - 비밀번호 입력창(TYPE_TEXT_VARIATION_PASSWORD) 감지 시 자동 입력 차단 │
│  - 조작 중 황금빛 외곽 테두리 오버레이(Floating Overlay) 시각 안내     │
└────────────────────────────────────────────────────────────────────────┘
```
